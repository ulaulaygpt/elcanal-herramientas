NORMALIZA

Tu texto, limpio y con un formato uniforme. Pega, revisa y copia. Así de sencillo.

Útil para textos de Word, PDF, páginas web y asistentes de IA. No reescribe las ideas; modifica la presentación y puede omitir elementos no textuales.

Gratuita · Sin registro · Procesamiento en tu navegador

Cómo quieres el texto

Decret@ es solo un ajuste opcional, no hace falta utilizar esa aplicación.

Personalizar formato

El texto no se envía a un servidor. Se guarda únicamente la preferencia de formato en este navegador.

Pega aquí el texto

Haz clic y pega con Ctrl+VPega un fragmento desde un documento o página web. También puedes usar el cuadro inferior, incluso desde un móvil.
El resultado aparecerá aquí.

Revisa siempre tablas, listas, imágenes y expresiones especiales antes de usar el resultado. Las imágenes se omiten y ciertos formatos pueden cambiar.

¿También sirve para Decret@?

Sí. Selecciona el ajuste «Compatible con Decret@» si necesitas pegar el resultado en ese editor. Es una compatibilidad orientativa basada en las pruebas disponibles, no una garantía para todas las versiones o documentos.
